# DWM shortcuts cheetsheet


```
Alt + shift + Enter  # 打开新窗口
Alt + shift + C  # 关闭当前窗口
Alt + D  # 窗口横向排列
Alt + I  # 窗口竖向排列
Alt + Enter  # 窗口位置互换
Alt + num  # 切换标签页
Alt + T  # 平铺模式 (tiling)
Alt + M  # 单窗口模式
Alt + F  # 浮动模式 (float)
# 窗口间切换
Alt + J
Alt + K
# 改变窗口的宽度
Alt + H
Alt + K
# 窗口模式切换
Alt + Space
Alt + shift + Space
# 在主副屏之间移动焦点
Alt + <
Mod + >
# 应用在主副屏间移动
Alt + shift + <
Alt + shift + >
# 缩放窗口
Alt + 鼠标邮件
```
